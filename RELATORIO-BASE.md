# Relatório técnico — Multimídia Educa

## 1. Identificação
Tema: Música e voz sintetizadas para Sistemas Multimídia.  
Tecnologia de autoria: React.js, JavaScript, HTML5 e CSS3.

Integrantes (ordem alfabética): preencher nomes completos e matrículas.

## 2. Objetivo
Desenvolver um protótipo educacional multimídia com navegação não linear para apresentar conceitos de música e voz sintetizadas.

## 3. Recursos de mídia
- Imagem matricial: `public/assets/capa-original.png`.
- Imagem vetorial: `public/assets/nota-vetorial.svg`.
- Áudio digitalizado: `public/assets/escala-sintetizada.wav`.
- Música MIDI: `public/assets/escala-original.mid`.
- Vídeo: `public/assets/aula-introducao.mp4`.
- Animação: animação CSS no módulo Galeria multimídia.

## 4. Ferramentas
React.js, Vite, Tone.js, @tonejs/midi, Lucide React, navegador e VS Code.

## 5. Quiz

## 6. Problemas encontrados

## 7. Produção das mídias
