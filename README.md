# Multimídia Educa

Protótipo educacional em React.js sobre **Música e voz sintetizadas para Sistemas Multimídia**.

## Requisitos
- Node.js 18 ou superior
- npm

## Executar
1. Extraia a pasta do projeto.
2. Abra a pasta no VS Code.
3. No terminal, execute:

```bash
npm install
npm run dev
```

4. Abra o endereço local mostrado pelo Vite (normalmente http://localhost:5173).

## Recursos implementados
- Navegação não linear entre módulos.
- Conteúdo sobre síntese musical, MIDI, áudio digital e voz sintetizada.
- Imagem matricial PNG original e ilustração vetorial SVG original.
- Áudio WAV original e arquivo MIDI original.
- Vídeo de apresentação em MP4 (quando gerado no ambiente de criação).
- Animação CSS/SVG.
- Quiz com banco de 15 questões, sorteio de 5 por tentativa e cálculo percentual.

## Observações para a entrega acadêmica
- O recurso de voz utiliza a SpeechSynthesis API do navegador. As vozes disponíveis dependem do sistema operacional e do navegador.
- O MIDI é reproduzido no navegador por Tone.js.
- Personalizem os textos, gravem uma narração própria e registrem fotos/vídeos feitos pelo grupo para atender à exigência de produção original.
- Incluam no relatório técnico os nomes, matrículas, evidências do processo de produção, equipamentos de captura e eventuais problemas encontrados.
- Antes da apresentação, testem áudio, vídeo e MIDI no computador que será utilizado.

## Estrutura
- `src/`: código React.
- `public/assets/`: mídias originais do protótipo.
